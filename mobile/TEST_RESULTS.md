# Android 客户端验证记录

验证日期：2026-10-22。以下是本次实际运行结果，非预计结果。

## 环境

- Flutter 3.47.7 / Dart 3.13.5，Android SDK 36，Gradle 8.14.3。
- 真机：Redmi K20 Pro，Android 14 / API 34，通过 USB 安装和控制测试。
- 电脑真实接口 `wlan0: 192.168.203.224/24`；手机接口 `wlan1: 192.168.203.79/24`。
- 电脑 Mihomo `Meta: 198.18.0.1/30` 始终存在，未关闭 TUN、未修改代理路由或防火墙。
- 测试 Go 服务独立使用 HTTP `18787`、UDP `8788`。原有 HTTP `8787` 进程未替换。
- `adb reverse --list` 为空；服务端日志确认手机来源是 `192.168.203.79`。USB 只用于安装、控制和取证，业务流量走真实局域网。

## 自动化通过

- `go test ./...`：全部通过；Go 竞态检查 `go test -race ./...` 通过。
- 新增 Go 测试覆盖：UUID 持久化、发现报文版本/请求标识、无效报文、虚拟网卡过滤、同子网来源约束、HTTP 端口合法性、端口占用、关闭后重新绑定、`/api/info` 新增字段及口令保护状态。
- 独立服务进程验证：无效发现端口不影响 HTTP、关闭发现、自定义发现端口，以及进程重启后 UUID 不变，均通过。
- `flutter analyze`：无问题。
- `flutter test`：6 个测试通过，覆盖发现请求匹配和去重、UUID 地址迁移选择、未找到原服务时不误连、HTTP / WebSocket Cookie 共用、重定向拒绝、离线输入保护、在线设备和文件消息界面。
- `flutter test integration_test/lan_test.dart -d 837613c6 --no-pub`：2 个真机集成测试通过。
- 真机自动发现和 `/api/info` UUID 校验通过，自动连接到 `http://192.168.203.224:18787`。
- 错误口令拒绝、正确口令加入、设备列表、群聊、私信、历史消息、安全存储读写通过。
- 真实 WebSocket 关闭后，自动重新发现和重连通过，服务端日志显示约 8 秒后重新上线。
- 上传从已写入 `333333` 字节的位置继续，完成后下载内容校验通过。
- 上传任务写入持久化存储、销毁客户端、重建客户端后恢复续传通过；这是客户端重建测试，不等同于上传中强制杀死 Android 进程。
- 取消上传后，本地文件和任务记录清理，服务端会话返回 404，通过。

- 手机通过 Android 系统文件选择器选择 `lanroom-check.bin` 上传，网页收到并通过浏览器下载。

独立 Go 服务进程停止再启动后，服务 UUID 保持不变；App 自动重新发现并提示输入口令，重新输入后恢复连接。符合服务端会话仅保存在内存中的现有行为。

## 验证边界

- 同一服务 UUID 更换 IP 的选择逻辑已通过自动化测试；未修改电脑网卡或 DHCP，未进行真实 IP 切换。
- 已验证真实连接断开后的自动重连；未切断承载当前会话的热点 / Wi-Fi，不能将其表述为物理网络切换测试。
- Android 17 / API 37 本地网络权限分支未在对应系统真机验证；当前编译和目标 SDK 为 36。
- 不承诺后台或锁屏持续在线。未验证 iOS、跨 VLAN、AP 隔离、多种路由器或所有 Mihomo 配置。
- 首次构建因标准 Maven 连接超时，使用临时 Gradle 用户目录和镜像配置完成；项目保留标准仓库，未改动全局 SDK 和代理配置。
- 构建存在 Flutter 对 AGP 8.11.1 / Kotlin 2.2.20 的未来版本支持提醒，当前构建成功，未跳过依赖版本校验。
